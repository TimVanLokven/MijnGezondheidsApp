# MijnGezondheidsApp

 Alle functies van de app staan in Dashboard. Via hier vult u in het formulier wat u gegeten hebt, wanneer en hoeveel van iedere voedingswaren erin zit die slaat u dan op. U kunt ook ieder item verwijderen. Let daarbij op dat u niet wordt gewaarschuwd als u op de verwijder knop drukt en het item gelijk verwijderd wordt.

 Ik heb de app gemaakt omdat ik graag mijn eetgedrag wil bijhouden omdat ik de laatste tijd ben bijgekomen qua gewicht.
